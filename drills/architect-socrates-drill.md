# Architect-Socrates Drill

Use this when a problem feels big, vague, or emotionally charged.

## Drill

1. What problem is this, exactly?
2. What assumptions am I carrying?
3. What is the smallest unit?
4. Where do responsibilities split?
5. Where can it fail?
6. What counterexample would embarrass this plan?
7. What is the first small experiment?

## Output

```text
problem:
assumptions:
smallest_unit:
responsibility_split:
failure_points:
counterexample:
first_experiment:
```

## Closure Rule

The drill is not complete until `first_experiment` is concrete enough to run or reject.
